# 트리
루트(제일 위),내부(중간의 모든 위치),리프(자식노드가 없는) 노드로 구성

문제풀때는 항상 루트먼저 검사해보자

노드 깊이 = 루트에서 해당 노드 까지 걸리는 길이

트리 높이 = 노드 깊이 중 가장 큰 값

트리의 집합 = 트리가 2개 이상 = 숲
## 이진트리
모든 노드에 대해서 자식 노드가 2개 이하인 경우

완전 이진 트리 : 리프 레벨 제외 모든 노드 채워짐, 리프 레벨은 왼쪽부터 채워져잇음

변질 이진 트리 : 선형 트리(모든노드가 자식이 하나만 있다)

포화 이진 트리 : 완전이진 트리에서 자식이 전부 잇는 경우

균형 이진 트리 : 모든 노드에서 왼쪽 오른쪽 높이 차이가 1 이하인경우
## 이진 탐색 트리(BST)
오른쪽 노드는 무조건 왼쪽보다 크다

AVL,레드블랙 -> 노드 삽입하면 알아서 트리가 회전하면서 균형 맞춘다
